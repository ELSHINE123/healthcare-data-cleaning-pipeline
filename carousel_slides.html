01 • Problem Statement

The Challenge: Real-World EHR Data is Messy

Why naive data cleaning breaks downstream medical machine learning.

1. Composite Vitals Formatting
  • Blood pressure stored as text string (e.g. "120/80").
  • Whitespace corruption prevents numeric analysis.
  • Required vectorized decomposition into systolic and diastolic.
2. Corrupted Types Data Types
  • The age column contained verbal words ("forty").
  • Decimal floats on completed integer patient years.
  • Required strict type coercion and nullable Int64 casting.
3. Polymorphic Dates Parsing
  • Dates recorded with inconsistent syntax across visits.
  • Mixed delimiters ("2023_04_15" vs "15-Apr-2023").
  • Standardized 100% of dates using fuzzy token parsing.
4. The "Ghost Patient" Risk Clinical Risk
  • Blind imputation on empty records fabricates synthetic patients.
  • Naive listwise deletion drops nearly 10% of real patients.
  • Needed an objective clinical triage rule to preserve power.
Core Clinical Dilemma:
How do we resolve 1,325 missing values across 1,000 records without inventing synthetic patients or destroying statistical power?
Solution: Domain-driven triage filter + stratified cascading median imputation.

02 • Pipeline Architecture

End-to-End Pipeline Workflow

A 5-stage production framework engineered for clinical reproducibility.

01

Text Normalization & Vital Splitting

Decomposed composite blood_pressure into numeric systolic_bp & diastolic_bp. Fixed typos ("forty" ➔ 40) and stripped all whitespace.

02

Resilient Timestamp Standardization

Applied dateutil.parser with fuzzy=True to resolve polymorphic delimiters, converting 100% of dates to datetime64[ns] without data loss.

03

The "Ghost Patient" Triage Filter

Audited 4 core clinical vitals (age, blood pressure, condition, cholesterol). Pruned 17 unrecoverable records (1.70% data loss) to prevent synthetic profile hallucination.

04

Hierarchical Cascading Median Imputation

3-tier stratified fallback: (Age Group + Gender) ➔ Gender Median ➔ Global Median. Preserves biological variance across demographics.

05

Regulatory Audit Flags & Anomaly Review

Created explicit provenance flags (*_imputed) mapped to 'Yes'/'No' for FDA/HIPAA compliance. Audited physiological bounds and IQR outliers.

04 • Code Implementation

Snapshot: Cascading Imputation

Stratified median hierarchy preserving demographic variation.

3. Hierarchical Cascading Median Imputation & Audit Tracking (Cells 39–50)
imputed_cols = ['systolic_bp', 'diastolic_bp', 'cholesterol'] for col in imputed_cols: df[col] = pd.to_numeric(df[col], errors='coerce') # Tier 1: Demographic subgroup median (Age Bracket + Biological Sex) subgroup_med = df.groupby(['age_group', 'gender'], observed=False)[col].transform('median') # Tier 2: Biological sex fallback median gender_med = df.groupby('gender', observed=False)[col].transform('median') # Tier 3: Global population median global_med = df[col].median() # Apply cascade fallback df[col] = df[col].fillna(subgroup_med).fillna(gender_med).fillna(global_med) # Convert boolean audit flags to regulatory 'Yes' / 'No' string labels bool_cols = df.select_dtypes(include='bool').columns df[bool_cols] = df[bool_cols].replace({True: 'Yes', False: 'No'})
Why Hierarchical Medians Over Global Means?
A 25-year-old female and a 75-year-old male have completely different healthy vital baselines.
Stratifying by age bracket and biological sex preserves genuine clinical distributions.

06 • Summary & Open Source

Key Takeaways & Repository

Core engineering lessons and link to the open-source repository.

1. Clinical Domain Rules > Generic Data Cleaning Lesson 1
  • Healthcare data cannot be treated like generic e-commerce clickstream data.
  • Imputing everything blindly invents patients; naive listwise deletion destroys real patients.
  • Objective triage filters based on core vitals strike the optimal statistical balance.
2. Explainability Matters in Regulated Environments Lesson 2
  • Stratified cascading medians are fast, 100% explainable, and have zero model-drift overhead.
  • Explicit boolean audit flags (*_imputed) ensure compliance with HIPAA and FDA 21 CFR.
  • Essential for medical AI models where training data provenance is heavily audited.
